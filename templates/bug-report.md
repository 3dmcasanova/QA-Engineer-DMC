# Bug report

| Field | Content |
|---|---|
| ID | `XXBG-01` |
| Title | [Component] What fails and when |
| Environment | Browser and version, resolution, OS, build |
| Precondition | State needed before reproducing |
| Steps to reproduce | 1. …<br>2. …<br>3. … |
| Expected result | What should happen (cite the requirement or design) |
| Actual result | What actually happened |
| Severity | Critical / High / Medium / Low |
| Priority | High / Medium / Low |
| Frequency | How often it reproduces, e.g. 5/5 |
| Evidence | Screenshot, video, console log or network request |
| Test case | ID of the test case that found it |
