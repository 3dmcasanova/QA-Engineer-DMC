# Test case

| Field | Content |
|---|---|
| ID | `XX-01` |
| Title | What is being checked, in one sentence |
| Precondition | What must be ready before starting |
| Steps | 1. …<br>2. …<br>3. … |
| Test data | Exact values to enter |
| Expected result | What should happen, per the requirement or design |
| Actual result | What actually happened |
| Status | Passed / Failed / Blocked |
| Bug ID | Only if the test fails |
