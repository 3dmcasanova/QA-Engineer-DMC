# Caso de prueba

| Campo | Contenido |
|---|---|
| ID | `XX-01` |
| Título | Qué se comprueba, en una frase |
| Condición previa | Qué debe estar listo antes de empezar |
| Pasos | 1. …<br>2. …<br>3. … |
| Datos de prueba | Valores exactos que se ingresan |
| Resultado esperado | Qué debería pasar, según el requisito o el diseño |
| Resultado obtenido | Qué pasó realmente |
| Estado | Aprobado / Fallido / Bloqueado |
| ID del bug | Solo si el caso falla |
